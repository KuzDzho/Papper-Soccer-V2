# «Бумажный футбол» — нативная версия для Android

Это отдельный проект Unity, не сайт в WebView. Он рассчитан на локальную игру без браузера и интернет-соединения.

## В этой версии

- Матч против ИИ с тремя уровнями сложности.
- Игра вдвоем на одном телефоне.
- Три размера поля: спринт (11×15), классика (11×19), марафон (11×25).
- Игра до 1, 3 или 5 очков.
- Пять оформлений поля: стадион, ночь, зима, пляж и тетрадь.
- Имена команд, восемь цветов, монетка перед матчем, правила, звук, реванш и отмена текущего хода.
- Настройки сохраняются на устройстве.
- Идентификатор Android: com.kudzho.papersoccer; target API 36; ARM64.

Сетевой режим не переносится в эту первую мобильную сборку: в исходном веб-проекте комнаты хранятся в localStorage и синхронизируются между вкладками одного браузера. Сервер для подключения разных телефонов в репозитории не найден.

## Установка Unity

1. Установи Unity Hub с официального сайта Unity.
2. Установи Unity 6.3 LTS.
3. В модулях установки отметь **Android Build Support**, **Android SDK & NDK Tools** и **OpenJDK**.
4. В Unity Hub выбери Add → Add project from disk и укажи папку UnityNative.
5. Открой проект и дождись окончания импорта. Если Unity предложит обновить проект, сперва сделай копию папки.

## Установка на телефон для проверки

1. В Unity открой Paper Soccer → Apply Android Store Settings.
2. Выбери Paper Soccer → Build Android APK (test).
3. После успешной сборки открой папку Builds и установи PaperSoccer-Test.apk на Android-телефон. Если установка заблокирована, разреши установку приложений из того источника, из которого ты открыл APK.

Для проверки можешь подключить телефон по USB и включить в настройках Android режим разработчика и USB debugging, затем выбрать устройство в Build Profiles.

## Подготовка публикации

1. В Unity открой Edit → Project Settings → Player → Android → Publishing Settings.
2. Создай свой keystore и alias. Сохрани файл и пароль в надежном месте.
3. Не загружай keystore и пароли в GitHub и не присылай их в чат. Для будущих обновлений используй тот же ключ.
4. Запусти Paper Soccer → Build Android App Bundle (AAB). Результат появится в Builds/PaperSoccer.aab.
5. Для RuStore можно также собрать подписанный APK через Paper Soccer → Build Android APK (release). RuStore принимает APK и AAB; подпись AAB дополнительно настраивается в консоли RuStore.
6. Загрузи AAB в Google Play Console и заполни карточку приложения и обязательные формы. Перед публикацией протестируй сборку на нескольких реальных телефонах.

По состоянию на 28 октября 2026 года Google Play требует target Android 16 / API 36 для новых приложений и обновлений, поэтому в проекте установлен API 36.

## Проверка

Исходники подготовлены, но сборка не была запущена в этой среде: здесь нет установленного Unity Editor и Android SDK. Поэтому APK/AAB еще не созданы и не проверены на реальном устройстве. Перед публикацией нужно открыть проект в Unity, выполнить тесты правил и собрать приложение.
